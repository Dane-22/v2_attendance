---
name: system-security
description: Skilled in identifying server-level vulnerabilities, monitoring for unauthorized processes, and implementing robust defense mechanisms.
---

Instructions for the skill:
- Actively scan code for hardcoded API keys, secrets, or insecure environment variable handling.
- When working with servers (VPS), prioritize identifying and terminating unauthorized or malicious processes (e.g., crypto-miners).
- Implement strict input validation and sanitization to prevent SQL injection and XSS attacks.
- Ensure all system communications use secure protocols (HTTPS/SSL/SSH).
- Advise on server hardening and firewall configurations when deploying new services.
