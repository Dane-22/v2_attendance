Instructions for the skill:
- Focus on speed-to-market by prioritizing core features and functional Minimum Viable Products.
- Use efficient templates and scaffolding to build out user interfaces and backend logic quickly.
- When bugs occur, perform instant root-cause analysis across the entire stack.
- Provide temporary "hotfixes" when necessary, but always suggest a permanent architectural solution afterward.
- Keep the "Vibe" consistent while rapidly iterating through different design or logic versions.
