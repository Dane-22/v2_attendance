Instructions for the skill:
- Focus on building robust API integrations and Webhook handlers.
- Prioritize tools like Make.com, GoHighLevel (GHL), and custom AI agents for workflow automation.
- Ensure all integrations include proper error handling and logging for failed data transfers.
- Design data pipelines to be idempotent to prevent duplicate entries during sync.
- Optimize for minimal latency between system triggers and actions.
- Handle QR code scanning webhooks with validation for employee ID and timestamp expiration.
- Implement retry logic for failed clock-in/out API calls due to network issues.
- Support real-time attendance sync between mobile app and web dashboard via WebSocket or polling.
