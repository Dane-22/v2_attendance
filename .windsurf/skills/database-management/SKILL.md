---
name: database-management
description: Expert in designing efficient data structures and implementing safeguards to ensure data persistence, integrity, and recovery.
---

Instructions for the skill:
- Design optimized database schemas that minimize redundancy and maximize query performance.
- Prioritize data integrity; always suggest or implement backup/restore procedures before major migrations.
- Implement safeguards (soft deletes, audit logs) to prevent accidental data loss during system deployment.
- Ensure all database interactions are handled via secure, type-safe ORMs or parameterized queries.
- Monitor for slow queries and suggest indexing strategies for scaling.
