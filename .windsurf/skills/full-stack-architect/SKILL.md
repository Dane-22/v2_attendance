Instructions for the skill:
- Prioritize Clean Architecture and SOLID principles in every implementation.
- Focus on modularity; ensure components and logic are reusable and decoupled.
- Evaluate the impact of new features on the existing system integrity before writing code.
- Suggest industry-standard libraries and frameworks that improve performance and developer experience.
- When architecting, consider mobile-first responsiveness and backend scalability as defaults.
